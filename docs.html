    Raport Studio documentation

    Raport Studio connects survey and Excel report data to the charts, tables and text boxes in a PowerPoint presentation. You wire up each slide once; after that, a new wave of data updates the whole deck in one click.

    Overview

    The add-in has three parts, all opened from the Raport Studio task pane (ribbon → Daniel's Add-ins → Raport Studio):

    Task pane

    The launcher. Opens the two studios, shows which data files are connected to this presentation and the current status. Keep it open while you work — the studios talk to PowerPoint through it.

    Data Processing Studio

    Turns raw respondent data (.sav or a flat .xlsx) into crosstab tables — banners, filters, totals, averages and significance — and sends them to the Studio.

    Studio

    The main workspace. A node canvas per slide where you pick data, shape it, and connect it to the objects on the slide.

    How data flows

    Excel report / crosstabs→ Data Explorer→ Nodes on the slide's canvas→ Chart / table / text box on the slide

    Everything — the canvases, the bindings and a copy of the imported data — is saved inside the presentation file itself. Reopening the deck later (or on another computer) restores all of it; you only need the Excel file again when you want newer numbers.

    Quick start

    1. Open the Studio. In the task pane, click Open Studio. It opens in its own window.
    2. Import your data. Click 1 Import Workbook in the toolbar and pick the Excel report (.xlsx). Its tables appear in the Data Explorer on the left. (Working from raw respondent data instead? Build the tables in Data Processing Studio first.)
    3. Scan the slides. Click 2 Scan Slides. Every slide and its objects appear in the Slides panel on the right.
    4. Pick a slide in the Slides panel. The canvas in the middle now belongs to that slide.
    5. Drag a question from the Data Explorer onto the canvas, then drag the target object (e.g. a chart) from the Slides panel onto the canvas.
    6. Wire them together, adding nodes in between to pick the rows/columns you need (right-click the canvas to add nodes). See Building a slide.
    7. Click Update Slide above the canvas. The slide updates in PowerPoint.
    8. Repeat for other slides. Next wave: import (or replace) the new file and click 4 Update Report to update every slide at once.

    Importing data

    Supported Excel reports

    The Studio reads tabulation reports and finds every table in them automatically. Two layouts are recognized:

    • "Column % / Column Comparisons" reports with a Tables worksheet (the usual export format).
    • QPSMR reports — detected from the structural codes in column A. Used automatically when the first layout isn't found.

    Each detected table becomes a question: a title, its rows (answer categories, base rows, NET rows…) and its columns (banners and waves, e.g. Region A: Sep '26).

    Crosstabs built in Data Processing Studio arrive in exactly the same shape, so everything below applies to them too.

    The Data Explorer

    • Questions are grouped by the file they came from. A blue database icon is an imported Excel report; teal means the file holds crosstabs from Data Processing Studio.
    • Hover a question for half a second to preview its table.
    • Search filters questions by title; the best matches are listed first.
    • Drag a question onto the canvas to use it (see Building a slide).
    • + Data File imports another file alongside the current ones — you can work with several files at once.
    • ⟳ on a file replaces it with a newer version (any file name). Questions that still exist in the new file stay connected to your canvases; you're told which ones no longer exist.
    • × removes a single question or a whole file.
    New wave? Use ⟳ on the existing file rather than removing and re-importing it — replacing keeps every wire on every slide connected.

    Data Processing Studio

    Use it when you have raw respondent data rather than a finished tabulation report. Open it from the task pane with Open Data Processing Studio.

    Datasets

    • Import Respondent Data (.sav) loads an SPSS file; a flat .xlsx (one row per respondent) works too.
    • Each import becomes a dataset in the left sidebar, with its respondent and question counts.
    • ⟳ on a dataset updates its data from a newer file and keeps every crosstab and folder.
    • Crosstab definitions are saved in the presentation, but the raw respondent rows are not. After reopening the deck, a dataset shows as needing its data: re-import the same file, or use ⟳ to load a newer one.

    Building a crosstab

    Click + New Crosstab (or the + on a folder), give it a Title, then choose what goes on each axis.

    SettingWhat it does
    Rows from / Columns fromOne question's answer values (e.g. a satisfaction question's answers), a banner of different variables (several breakdowns side by side, e.g. Age, Region, Gender — each with its own label and order), or another crosstab's rows/columns (reuse an existing table's layout).
    Combining categoriesType the same label on two rows of the column list to merge them into one column (e.g. two regions into "South").
    Total columnInclude a "Total" column — every respondent, regardless of the column category.
    Average rowInclude an Average row, computed either from a different, numeric question (e.g. exact years owned) or from values you assign to the row categories (e.g. "1-3 years" → 2; rows left blank are excluded).
    FiltersRestrict the respondents. All conditions must match (AND); ticking several values inside one condition means "any of". Multi-answer questions offer is any of / none of / all of.
    SignificanceSignificance testing (arrows, column vs. column) at 90 / 95 / 99%. With several banners, choose between testing within each banner only (e.g. within Age, within Region) or between banners (same-named columns compared across banners).
    DecimalsThe .0← / →.00 buttons decrease / increase decimal places.
    Swap axesSwaps rows and columns and recomputes the table.
    ReorderingDrag a column header or row label in the preview to reorder it.

    Each crosstab computes column percentages, plus a NET row and a Column Sample Size row (the base), which the Studio's Sig Dif nodes can use.

    Sending crosstabs to the Studio

    Click Add to Workbook. The crosstab appears in the Studio's Data Explorer under the dataset's file name, with a teal icon. After you change it (a label, a filter, an order…), the button reads Update in Workbook — click it again to push the change. Slides already wired to that crosstab keep their connections.

    Organizing and exporting

    • Folders: + New Folder (and subfolders from a folder's own buttons); drag crosstabs into them and drag to reorder. Double-click a name to rename it. Deleting a folder moves its contents up a level.
    • Duplicate a crosstab to start a variation from it.
    • Export to Excel: tick crosstabs (or whole folders) and download them as one .xlsx. Folders become section headings. With nothing ticked, everything is exported. A single crosstab can also be downloaded from its own toolbar.

    Building a slide

    Each slide has its own canvas. A canvas is a small pipeline: data comes in on the left, gets shaped by nodes, and goes out on the right into an object on the slide.

    Example: a chart showing three columns of one question

    Q1. Satisfaction→ Get Rows+ Get Columns→ Display as Table→ Chart 3 (PowerPoint)
    1. Select the slide in the Slides panel.
    2. Drag Q1 from the Data Explorer onto the canvas. This creates a question node showing its row and column count.
    3. Right-click the canvas → Select → Get Rows. Wire the question's Output into its Input, then pick the rows you want with + Add row.
    4. Do the same with Get Columns for the columns (e.g. Total and two regions).
    5. Add Tables → Display as Table. Wire Get Rows into its Rows input and Get Columns into Columns. It shows a live preview of the resulting table — check the numbers here.
    6. Expand the slide in the Slides panel and drag the chart onto the canvas. This creates its PowerPoint output node.
    7. Wire Display as Table's Output into the chart node, then click Update Slide.
    Faster wiring: drag a wire from any output and release it on empty canvas — the add-node menu opens and the node you pick is connected automatically.

    Text works the same way: build a value (e.g. with Get Rows + Get Columns down to a single cell), then feed it into a Text Template such as Satisfaction reached {{score}} this wave, and wire that into a text box.

    Working on the canvas

    ActionHow
    Add a nodeRight-click empty canvas. Browse the categories, or just type to search (↑ ↓ to choose, Enter to add). Searching also finds questions by title and adds them as question nodes.
    ConnectDrag from an output dot (right side of a node) to an input dot (left side).
    Connect to a new nodeDrag a wire out and release it on empty canvas — the add-node menu opens and auto-connects what you pick. Releasing it on top of an existing wire splices the new node into that wire.
    Move a wireGrab a wire right at its end and drop it on another dot.
    Move all wires at onceHold Ctrl while you start dragging from a dot that has several wires — they all come with you. Drop them on another dot of the same kind (output → output, input → input). Release on empty canvas or press Esc to cancel.
    Delete a wireRight-click it.
    Add a bend pointDouble-click a wire to drop a reroute dot you can drag to tidy the layout.
    See what a wire connectsHover over it for about a second — both ends are highlighted.
    SelectClick a node; drag a box on empty canvas to select several (nodes must be fully inside the box).
    Pan / zoomDrag with the middle or right mouse button to pan; scroll to zoom. The minimap (bottom right) can be dragged too.
    Resize a nodeSelect it and drag its edges. Nodes also grow by themselves to fit their content.
    Open a groupDouble-click it. Use the breadcrumb above the canvas (starting at Base) to go back out.
    Rename a nodeSelect it and edit Title in the Properties panel.

    Node reference

    Nodes are grouped exactly like the add-node menu. Each node's color matches its category. Most nodes take a table in on Input and pass a table out on Output; every node shows a live preview or a short status so you can check each step.

    Select — pick parts of a table

    NodeWhat it does
    Get RowsKeeps only the rows you pick (+ Add row). Each picked row also has its own output dot, and extra Value / Label outputs sit at the bottom.
    Get ColumnsKeeps only the columns you pick. Any column slot can be wired instead of picked — e.g. from a Column from Variable node.
    Exclude RowsThe opposite of Get Rows: keeps every row except the ones picked. Can also exclude the sig-diff letter rows.
    Exclude ColumnsThe opposite of Get Columns.
    Get BannerKeeps whole banner/split groups (e.g. Total, Region A) with every wave under them.
    Column from VariablePicks the column matching a variable's current value (e.g. Sep '26) under every banner at once. Shown in red.
    Get LabelOutputs a row's or column's label text instead of its numbers — useful inside text templates.

    Tables — build, combine and preview

    NodeWhat it does
    Display as TableMerges a Rows input and a Columns input (from the same question) into a table and shows it. The most common last step before a chart or table.
    Preview TableShows a single input that's already a complete table.
    Assemble TableLike Display as Table, but with as many Row and Column inputs as you need (+ Add row / + Add column), all from the same question.
    Combine TablesJoins tables from different questions. Combine by: Stacking rows (same columns) or Merging columns (same rows).
    Manual TableA table you type in by hand — headers, row labels and values, no workbook needed. Runs: Always, or When triggered by a Branch node's If/Else output.
    Table TemplateFull per-cell control over an output table: every cell has its own text with {{variables}}, drawn from a shared pool of wired-in values.

    Table previews let you set a number format per column in the header: format (e.g. Percentage) and decimal places with .0← / →.00.

    Labels & Text

    NodeWhat it does
    Rename LabelsA list of one-off renames: wire in a single row or column, type its new label. Each rename's renamed to input can also be wired from a Compose Text node.
    Rename by PatternLearns a renaming rule from 2+ examples and applies it to every matching label — e.g. …Brand X 2020 (l) → '20 and …Brand X 2021 (m) → '21 also renames 2022, 2023 and any future wave.
    Label TemplateRebuilds every column header (or row label) from a template. {{label}} is the current label, {{value}} the matching cell of the table wired into Values — e.g. '20 (509) with the base in brackets.
    Text TemplateWrites text with live numbers: type text with {{name}} placeholders, wire one input per variable, then wire the output into a text box. Has a formatting toolbar (bold, italic, underline, strikethrough, font, size, color, indent/list level).
    Compose TextBuilds a short text from wired values only (no Data input) — typically to feed a Rename Labels renamed to input.

    Math, Values & Arrange

    NodeWhat it does
    Add / Subtract / Multiply / DivideCombines two or more branches cell by cell. Any operand can be a typed-in number instead of a wire.
    Sum / AverageTotals or averages the table Down each column (one row out) or Across each row (one column out). Average skips empty cells.
    ScaleMultiplies every number by a factor.
    RoundRounds every number to N decimals.
    To Percentage (%)×100 and adds "%" — 0.7 → 70%.
    From Percentage (%)÷100 — 70% → 0.7.
    Replace Empty ValuesFills blank cells with a fixed value (default 0).
    SortSort rows or Sort columns — by label, by a column's (or row's) value, by date, or by another table's order — ascending or descending. The sort column can also be wired in.
    TransposeSwaps rows and columns.
    Reverse Rows / ColumnsReverses the order.
    Skip First Row / ColumnDrops the first row or column.

    Significance

    NodeWhat it does
    Sig Dif (Calculate)Runs the significance test itself: a two-proportion z-test between columns at the chosen Confidence (90 / 95 / 99%, or two levels at once — capitals for the higher, small letters for the lower). Wire Data plus the Base (n) row (e.g. Column Sample Size).
    Sig Dif (From Workbook)Doesn't calculate anything — reads the significance letters already printed in the imported report's cells. Wire only Data.
    Has Sig DifA yes/no condition: TRUE when any row in the chosen column carries a significance mark. Feeds a Branch node.
    Keep Sig Dif RowsKeeps only the rows where at least one cell was marked significant.

    Sig Dif options

    • Mark — how a significant cell is shown: Letters (the letters of the columns it beats), Arrows, Arrows + color, or Arrows + color + ppt.
    • Compare — Each vs each other, Each vs first column, or Each vs previous column (e.g. this wave vs last wave).
    • Rows / Columns — test All, or only Specific ones.
    • Compare across banners? — normally columns are only compared within their own banner (Age vs Age). Turn this on to compare every column against every other.
    • Text options control how the mark looks in chart data labels: arrow glyphs for higher/lower, value size/bold, data label color, and a space before the mark.

    Logic & Chart

    NodeWhat it does
    Greater Than / Less Than / EqualA yes/no condition comparing A with B (wired, or a typed number). Equal also compares text, e.g. a label.
    Branch (If/Else)A gate: wire Data and a condition. If passes the data through when the condition is true, Else when it's false. Condition dots are square and green.
    Chart ColorsGives each Category (row label) or Series (column label) its own fill color in the bound chart — e.g. always show Brand A in red. Place it between your data and the chart.

    Inputs, outputs and organizing

    NodeWhat it does
    Question nodeCreated by dragging a question from the Data Explorer (or searching for it in the add-node menu). Outputs the whole table.
    PowerPoint output nodeCreated by dragging an object from the Slides panel. Shows the object's type and whether it's claimed (found on the slide) or unclaimed (missing — see Repair). If PowerPoint can't tell the type (e.g. an empty content placeholder), pick it yourself. For charts: Start cell — leave blank to update the chart's data where it already is; set it only to move the data. Resize data range — also stretches the chart's series over every written column/row, so new waves join the chart.
    CommentA colored frame with a title and note, for labelling parts of the canvas (C). Drag it by its title bar; color and note are in Properties.
    GroupSeveral nodes collapsed into one box with named input/output pins (Ctrl+G). Double-click to open and edit the inside.
    RerouteA bend point on a wire (double-click a wire).

    Variables

    A variable is a named value you define once and use on any number of slides — most often the current wave. Change the value once, and every node that uses it follows on the next update.

    1. In the Variables panel, click + Variable.
    2. Select it and, in Properties, set its Name (e.g. Current Wave) and Value. File and Banner only narrow the list of values offered; they don't affect matching.
    3. Drag the variable onto a canvas. This creates a Column from Variable node; wire a question into it.

    The value is matched against the part of each column label after the banner name, so Sep '26 matches Sep '26, Region A: Sep '26, Region B: Sep '26 and so on — in every question and every file that names the wave the same way. The node lists what it matched.

    Next wave in one step: import the new data, change Current Wave to the new wave, then Update Report.

    Updating the report

    ButtonWhat it does
    Update SlideAbove the canvas. Writes everything wired on the current slide to PowerPoint.
    4 Update ReportRescans the deck, then updates every slide: text boxes, tables and templates first, then all charts.
    3 RefreshRuns validation, then re-applies every binding in the project. If no workbook is loaded, it asks you to import one first.
    • Text boxes and tables update in about a second.
    • Charts take longer: PowerPoint rebuilds the slide to rewrite the chart's data. A slide with several charts can take a few minutes; the status bar shows progress. The slide keeps its look and position, but gets a new internal identity, which the Studio tracks for you.
    • Outputs whose data and wiring haven't changed since the last update in this session are skipped, so repeated updates are fast.
    • After an update the Studio reloads itself to pick up the refreshed slides.
    Let updates finish. Don't close the Studio or PowerPoint while charts are updating. If it happens anyway, nothing is lost — see Recovery.

    Saving & sharing

    • Automatic: every change is saved into the presentation a moment after you make it. Saving the .pptx as usual keeps it; the imported data is stored with it too.
    • Save Project Now forces that save immediately.
    • Save Project downloads the whole project (canvases, bindings and data) as a .json backup.
    • Load Project loads such a .json back — handy for reusing a setup in a similar deck.

    To share the work, just share the presentation: whoever opens it with the add-in gets every canvas and binding.

    Troubleshooting

    Validation

    Click Run Validation in the bottom panel. Problems appear under Errors and Warnings; click one to jump to the node involved. Warnings you've checked can be dismissed.

    CodeMeaning and fix
    MISSING_QUESTIONA question the project expects isn't in the imported data — usually the new file renamed or dropped a table. Check the Data Explorer and re-wire the affected slide.
    UNRESOLVED_COLUMNA binding points at a question that isn't in the current workbook. Import the file it came from, or re-wire it.
    TRANSFORM_ERRORA node couldn't compute — e.g. an input isn't connected, a template variable has no value, or a picked row/column no longer exists. The message names the node.
    DUPLICATE_BINDINGTwo bindings write to the same object; only the first is used. Remove the extra one.
    ORPHANED_TAGA shape carries a binding that's no longer in the project (copied from another deck, or edited outside the Studio). Usually harmless; re-bind it if it should update.

    Repair: a bound object was deleted

    If an object a binding writes to no longer exists, its output node shows unclaimed and validation lists it with a Repair button. Click it, choose the slide, and Confirm — the object is recreated there and bound again.

    Recovery: a canvas went missing after an update

    If the Studio was closed (or froze) while charts were updating, the update still finishes in PowerPoint, but the canvas can end up attached to the slide's old identity. A Recovery tab then appears in the bottom panel. Nothing is deleted: pick the slide the canvas belongs to and click Reattach.

    Common problems

    ProblemWhat to do
    The Studio window doesn't openA popup blocker may have stopped it. Allow popups for the add-in and click Open Studio again.
    The Studio stopped responding to PowerPointKeep the task pane open — the Studio works through it. Close the Studio, reopen it from the task pane.
    "No tables detected"The file isn't a recognized report layout (see Importing data). For raw respondent data, use Data Processing Studio.
    An output node's type is wrongEmpty content placeholders can't report a type. Pick the type in the output node.
    A chart doesn't show new wavesTurn on Resize data range in the chart's output node.
    Can't find a nodeRight-click the canvas and type part of its name. Renamed nodes are also found by their old names.
    Lost on the canvasPress F to frame every node.
    Ribbon or title still shows old names after an add-in updateClose PowerPoint, clear %LOCALAPPDATA%\Microsoft\Office\16.0\Wef\, and reopen.
